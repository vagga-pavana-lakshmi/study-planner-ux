# Mobile Study Planner — UX Case Study

A mobile study planner concept designed to help college students organize study tasks, manage subjects, and track their study progress.

## Project Overview

This project focuses on the early-stage UX design of a simple mobile study planner.

The design process includes user research, user persona creation, user flow planning, low-fidelity wireframing, and design thinking.

## User Research

The research focused on understanding common study-planning difficulties faced by college students.

Key needs identified:

- Organizing multiple subjects and study tasks
- Quickly recording study tasks
- Viewing daily study activities clearly
- Marking completed tasks
- Tracking study progress

## User Persona & User Flow

A student persona was created to represent the target user and understand their goals, needs, and pain points.

The main user flow is:

**Welcome → Dashboard → Subjects → Add Study Task → Task Details → Progress**

## Low-Fidelity Wireframes

The wireframes focus on the basic structure and navigation of the mobile application without detailed visual styling.

The main screens include:

1. Welcome / Login
2. Home / Dashboard
3. My Subjects
4. Add Study Task
5. Task Details
6. Progress

## Design Thinking Process

The design process follows:

**Empathize → Define → Ideate → Prototype → Test → Iterate**

The goal is to create a simple and easy-to-use study planning experience.
